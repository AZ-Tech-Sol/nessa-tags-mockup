# nessa-tags-mockup: forwarder only

Nessa's own NFC tag opens https://az-tech-sol.github.io/nessa-tags-mockup/. This repo now only forwards every visit to
**https://nessa.aztechsol.com/** with `utm_source=nfc&utm_medium=tag&utm_campaign=nessa`, so tag taps count in Umami as
`tag-tap` without rewriting the tag. The live site is **AZ-Tech-Sol/nessa-tags**. Don't delete this repo while tags point here.
